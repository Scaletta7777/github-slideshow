# Product Photo Bot

Личный Telegram-бот: фото товара → профессиональная карточка для маркетплейса (через OpenAI Images API).

## Что умеет

1. Присылаете фото товара (с телефона; лучше **файлом**, без сжатия).
2. Выбираете концепт: каталог на белом, цветная студия, подиум, интерьер, на модели, flat lay, природа, премиум — или пишете **свой сценарий**.
3. Переключаете формат: **3:4** (Wildberries / Ozon / Uzum) или **1:1** (Amazon / Etsy) и число вариантов за раз: **1 / 2 / 4** (каждый вариант оплачивается отдельно).
4. Получаете фото и файлы в полном качестве. Кнопки под каждым файлом относятся именно к нему:
   - **✏️ Доработать**: пишете, что изменить («сделай фон светлее», «убери тень»), и бот правит эту картинку;
   - **🔁 Ещё вариант** и **🎨 Другой концепт**.
5. Инфографика (накладывается на тот вариант, под которым нажата кнопка):
   - **🅰️ Точный текст** — текст рисуется шаблоном, без ошибок в буквах, бесплатно (без запроса к API);
   - **✨ ИИ-дизайн** — нейросеть оформляет карточку как дизайнер маркетплейса. Можно выбрать стиль (минимализм, элегантный, журнальный, яркие бейджи) или «🎲 3 разных стиля сразу», а текст написать самому или нажать «✨ Придумай текст сам» (язык задаётся в `CARD_LANGUAGE`).

6. **🖼 Карточка по референсу** (`/ref`): присылаете карточку, стиль которой нравится (с маркетплейса, Aidentika, Pinterest), затем фото товара, и бот делает вашу карточку в том же стиле: раскладка, шрифты, цвета, бейджи. Понравившийся стиль можно сохранить кнопкой «📌 Запомнить этот стиль».
7. **🤖 ИИ-арт-директор**: в выборе стиля инфографики кнопки «ИИ подберёт стиль» и «ИИ: 3 варианта». Текстовая модель (`OPENAI_TEXT_MODEL`) смотрит на товар, определяет категорию и покупателя, сама выбирает дизайн и пишет текст.
8. **📌 Библиотека образцов**: `/addstyle` — прислать карточку-образец, бот запомнит стиль, и он появится среди кнопок стилей; арт-директор тоже будет его предлагать. `/styles` — список и удаление. Образцы хранятся в папке `styles/`.

9. **📚 Серия слайдов**: кнопка под любой карточкой. Она становится обложкой, а бот добавляет 3, 5 или 7 слайдов в том же стиле (всего до 8 фото): преимущества, детали, товар в использовании, размеры, состав. Цифры берутся только из характеристик, которые вы присылаете.
11. **Надёжность**: каждая готовая картинка сохраняется на сервере в папке `output/`; если Telegram не принял файл, бот повторяет отправку, а **/resend** присылает последние результаты ещё раз.
10. **⬇️ /update** скачивает свежую версию с GitHub и перезапускает бота, **🔄 /restart** просто перезапускает.

Бот отвечает только пользователям из `ALLOWED_USER_IDS`.

## Запуск

Нужен Python 3.10–3.14, лучше 3.13 (на Windows при установке отметьте «Add Python to PATH»).

**Проще всего:** дважды кликните `start.bat` (Windows) или запустите `./start.sh` (macOS / Linux).
При первом запуске скрипт установит зависимости и откроет `.env`: впишите туда ключи (см. ниже) и запустите скрипт снова.

Вручную:

```bash
cd product_bot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot`;
- `OPENAI_API_KEY` — ключ на <https://platform.openai.com/api-keys>. Это **API-ключ**, подписка ChatGPT Plus для него не подходит: баланс пополняется отдельно в разделе Billing. Для генерации картинок организацию, возможно, придётся верифицировать (Settings → Organization → Verify);
- `ALLOWED_USER_IDS` — оставьте пустым, запустите бота и напишите ему: он пришлёт ваш ID. Впишите его и перезапустите.

```bash
python bot.py
```

Бот работает, пока запущена программа. Чтобы он работал постоянно, запустите его на VPS (например, через `systemd` или `screen`).

## Запуск на сервере 24/7 (Ubuntu / Debian)

Бот ставится в отдельную папку `~/product_bot` и отдельную службу `product-bot`, поэтому другие боты на сервере не затрагиваются. По SSH выполните:

```bash
curl -fsSLO https://raw.githubusercontent.com/Scaletta7777/github-slideshow/claude/aidentika-bot-clone-fwg076/product_bot/install_server.sh && bash install_server.sh
```

Скрипт спросит токен бота, ключ OpenAI и ваш Telegram ID, затем запустит бота как службу systemd: бот сам стартует после перезагрузки сервера и перезапускается при сбое. Логи: `journalctl -u product-bot -f`.

⚠️ Один и тот же токен нельзя запускать в двух местах одновременно: после запуска на сервере остановите бота на компьютере.

## Настройки

| Переменная | По умолчанию | Описание |
|---|---|---|
| `OPENAI_IMAGE_MODEL` | `gpt-image-2` | также `gpt-image-1.5`, `gpt-image-1`, `gpt-image-1-mini` (дешевле) |
| `OPENAI_IMAGE_QUALITY` | `high` | `low` / `medium` / `high`, влияет на цену |
| `OPENAI_TEXT_MODEL` | `gpt-5.4-mini` | модель арт-директора, которая анализирует фото и референсы |
| `CARD_LANGUAGE` | `Russian` | язык текста, который бот придумывает сам (`English`, `Uzbek`…) |
| `FONT_PATH` | авто | `.ttf`-шрифт для инфографики (по умолчанию ищется Arial / DejaVu) |

Концепты и промпты лежат в `concepts.py`, их можно править и добавлять новые.
