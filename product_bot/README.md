# Product Photo Bot

Личный Telegram-бот: фото товара → профессиональная карточка для маркетплейса (через OpenAI Images API).

## Что умеет

1. Присылаете фото товара (с телефона; лучше **файлом**, без сжатия).
2. Выбираете концепт: каталог на белом, цветная студия, подиум, интерьер, на модели, flat lay, природа, премиум — или пишете **свой сценарий**.
3. Переключаете формат: **3:4** (Wildberries / Ozon / Uzum) или **1:1** (Amazon / Etsy) и число вариантов за раз: **1 / 2 / 4** (каждый вариант оплачивается отдельно).
4. Получаете фото и файлы в полном качестве. Кнопки под каждым файлом относятся именно к нему:
   - **✏️ Доработать**: пишете, что изменить («сделай фон светлее», «убери тень»), и бот правит эту картинку;
   - **🔁 Ещё вариант** и **🎨 Другой концепт**.
5. Инфографика (накладывается на тот вариант, под которым нажата кнопка):
   - **🅰️ Точный текст** — текст рисуется шаблоном, без ошибок в буквах, бесплатно (без запроса к API);
   - **✨ ИИ-дизайн** — нейросеть сама оформляет карточку (красивее, но может ошибиться в тексте).

Бот отвечает только пользователям из `ALLOWED_USER_IDS`.

## Запуск

Нужен Python 3.10–3.14, лучше 3.13 (на Windows при установке отметьте «Add Python to PATH»).

**Проще всего:** дважды кликните `start.bat` (Windows) или запустите `./start.sh` (macOS / Linux).
При первом запуске скрипт установит зависимости и откроет `.env`: впишите туда ключи (см. ниже) и запустите скрипт снова.

Вручную:

```bash
cd product_bot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot`;
- `OPENAI_API_KEY` — ключ на <https://platform.openai.com/api-keys>. Это **API-ключ**, подписка ChatGPT Plus для него не подходит: баланс пополняется отдельно в разделе Billing. Для генерации картинок организацию, возможно, придётся верифицировать (Settings → Organization → Verify);
- `ALLOWED_USER_IDS` — оставьте пустым, запустите бота и напишите ему: он пришлёт ваш ID. Впишите его и перезапустите.

```bash
python bot.py
```

Бот работает, пока запущена программа. Чтобы он работал постоянно, запустите его на VPS (например, через `systemd` или `screen`).

## Настройки

| Переменная | По умолчанию | Описание |
|---|---|---|
| `OPENAI_IMAGE_MODEL` | `gpt-image-2` | также `gpt-image-1.5`, `gpt-image-1`, `gpt-image-1-mini` (дешевле) |
| `OPENAI_IMAGE_QUALITY` | `high` | `low` / `medium` / `high`, влияет на цену |
| `FONT_PATH` | авто | `.ttf`-шрифт для инфографики (по умолчанию ищется Arial / DejaVu) |

Концепты и промпты лежат в `concepts.py`, их можно править и добавлять новые.
